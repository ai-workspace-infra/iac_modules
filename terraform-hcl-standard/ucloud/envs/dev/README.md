# UCloud dev environment

Minimal example composition for the reusable modules in `../../modules`. Configure
credentials with `UCLOUD_PUBLIC_KEY`, `UCLOUD_PRIVATE_KEY`, `UCLOUD_PROJECT_ID`,
and `UCLOUD_REGION`; provide the image, zone, and security group IDs for your
account and region through `terraform.tfvars` or `TF_VAR_*` variables.
